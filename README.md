# HPC Basics

Learn how to use UVA Research Computing (RC) HPC resources: access, Open OnDemand interactive apps, batch jobs, and where to get help.

## Getting Started

Clone this repository and explore the docs:

```bash
git clone https://github.com/UVADS/hpc-basics.git
cd hpc-basics
```

Published site: [https://uvads.github.io/hpc-basics/](https://uvads.github.io/hpc-basics/)

## Contents

- **RC Services**: HPC/GPU resources and storage
- **Getting access**: how to get an RC account and connect
- **Open OnDemand interactive apps**: JupyterLab, RStudio, VS Code, Desktop
- **Running a batch job**: submitting and managing jobs
- **Tools**: common software and workflows on HPC
- **Getting help**: RC documentation and support contacts
